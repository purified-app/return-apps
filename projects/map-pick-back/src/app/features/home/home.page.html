MapPickBack

Pick a map pin and return it to the app you came from

Leaflet map helper that other web apps can open. Tap the map to place a pin, then Done redirects the coordinates back via URL.

Open map Try demo caller

Integration

Open the map:

?returnUrl=<urlencoded-https-url>&state=<optional>&lat=<optional>&lng=<optional>&zoom=<optional>

After Done, redirect to:

<returnUrl>?lat=<lat>&lng=<lng>&zoom=<zoom>&format=map-pin&state=<state>

Demo URL example

Open MapPickBack and return to the built-in demo caller:

{{ demoOpenUrl }}

Example return shape:

{{ demoReturnUrl }}

Without returnUrl, the pin is shown in the app (standalone mode). returnUrl must be https: (or http://localhost).
