MapPickBack

Pick a map point and return it to the app you came from

Leaflet map pin picker. After Done, the point is returned as value (lat,lng) with zoom (query by default).

Open map Try demo caller

Integration

Open:

?returnUrl=<url>&state=<optional>&allowedOrigins=<optional>&lat=&lng=&zoom=

Return:

<returnUrl>?value=<lat>,<lng>&format=map.point&lat=&lng=&zoom=&state=<state>
