ScanBack

Scan a code and return it to the app you came from

Camera barcode scanner that other web apps can open. After a successful scan, the value is returned via value + format=scan.* (query by default).

Start scanning Try demo caller

Integration

Open:

?returnUrl=<url>&state=<optional>&allowedOrigins=<optional>&delivery=query&formats=<optional>

Return:

<returnUrl>?value=<payload>&format=scan.qr_code&state=<state>
