SignBack

Capture a signature and return it to the app you came from

Mobile-first signature pad that other web apps can open. After Done, the signature SVG is returned as value + format=sign.svg (hash by default).

Start signing Try demo caller

Integration

Open:

?returnUrl=<url>&state=<optional>&allowedOrigins=<optional>&delivery=hash

Return:

<returnUrl>#value=<svg-data-url>&format=sign.svg&state=<state>
