SignBack

Capture a signature and return it to the app you came from

Mobile-first signature pad that other web apps can open. After Done, the signature is redirected back via URL as SVG.

Start signing Try demo caller

Integration

Open the pad:

?returnUrl=<urlencoded-https-url>&state=<optional>

After Done, redirect to:

<returnUrl>?signature=<svg-data-url>&format=image/svg+xml&state=<state>

Demo URL example

Open SignBack and return to the built-in demo caller:

{{ demoOpenUrl }}

Example return shape:

{{ demoReturnUrl }}

Without returnUrl, the signature is shown in the app (standalone mode). returnUrl must be https: (or http://localhost).
