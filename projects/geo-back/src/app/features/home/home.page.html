GeoBack

Capture GPS coordinates and return them to the app you came from

Mobile-first geolocation helper that other web apps can open. After a successful reading, the coordinates are redirected back via URL.

Get location Try demo caller

Integration

Open the locator:

?returnUrl=<urlencoded-https-url>&state=<optional>&highAccuracy=<optional>

After success, redirect to:

<returnUrl>?lat=<lat>&lng=<lng>&accuracy=<meters>&format=geo&state=<state>

Demo URL example

Open GeoBack and return to the built-in demo caller:

{{ demoOpenUrl }}

Example return shape:

{{ demoReturnUrl }}

Without returnUrl, the reading is shown in the app (standalone mode). returnUrl must be https: (or http://localhost).
