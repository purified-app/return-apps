GeoBack

Capture GPS coordinates and return them to the app you came from

Mobile-first geolocation helper. After a successful reading, coordinates are returned as value (lat,lng) plus extras (query by default).

Get location Try demo caller

Integration

Open:

?returnUrl=<url>&state=<optional>&allowedOrigins=<optional>&highAccuracy=<optional>

Return:

<returnUrl>?value=<lat>,<lng>&format=geo.point&lat=&lng=&accuracy=&timestamp=&state=<state>
