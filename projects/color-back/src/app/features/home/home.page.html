ColorBack

Sample a color from the camera and return it to the app you came from

Mobile-first eyedropper that other web apps can open. Aim the crosshair, tap Use color, and the hex/RGB values redirect back via URL.

Open eyedropper Try demo caller

Integration

Open the eyedropper:

?returnUrl=<urlencoded-https-url>&state=<optional>

After Use color, redirect to:

<returnUrl>?hex=<%23rrggbb>&rgb=<r,g,b>&format=hex&state=<state>

Demo URL example

Open ColorBack and return to the built-in demo caller:

{{ demoOpenUrl }}

Example return shape:

{{ demoReturnUrl }}

Requires camera permission and HTTPS (or localhost). Without returnUrl, the color is shown in the app (standalone mode).
