ColorBack

Sample a color and return it to the app you came from

Camera eyedropper. After Use color, the hex value is returned with an rgb extra (query by default).

Open eyedropper Try demo caller

Integration

Open:

?returnUrl=<url>&state=<optional>&allowedOrigins=<optional>

Return:

<returnUrl>?value=#rrggbb&format=color.hex&rgb=r,g,b&state=<state>

Requires camera permission and HTTPS (or localhost). Without returnUrl, the color stays in the app.
