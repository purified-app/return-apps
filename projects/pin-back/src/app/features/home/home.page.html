PinBack

Enter a PIN and return it to the app you came from

Fullscreen numeric keypad that other web apps can open. After Done, the PIN is redirected back via URL.

Enter PIN Try demo caller

Integration

Open the keypad:

?returnUrl=<urlencoded-https-url>&state=<optional>&length=<optional>&mask=<optional>

After Done, redirect to:

<returnUrl>?pin=<digits>&format=pin&state=<state>

Demo URL example

Open PinBack and return to the built-in demo caller:

{{ demoOpenUrl }}

Example return shape:

{{ demoReturnUrl }}

Without returnUrl, the PIN is shown in the app (standalone mode). returnUrl must be https: (or http://localhost).
