NfcBack

Read an NFC tag and return it to the app you came from

Web NFC reader (Chrome/Android). Returns value + format=nfc.* with recordType (query by default).

Start NFC scan Try demo caller

Integration

Open:

?returnUrl=<url>&state=<optional>&allowedOrigins=<optional>

Return:

<returnUrl>?value=<payload>&format=nfc.url&recordType=url&state=<state>

Requires HTTPS and Web NFC (Chrome on Android).
