NfcBack

Read an NFC tag and return it to the app you came from

Web NFC helper (Chromium on Android) that other web apps can open. After a successful read, the tag payload is redirected back via URL.

Start NFC scan Try demo caller

Integration

Open the reader:

/nfc?returnUrl=<urlencoded-https-url>&state=<optional>

After a successful read, redirect to:

<returnUrl>?nfcValue=<value>&recordType=<type>&format=nfc&state=<state>

Demo URL example

Open NfcBack and return to the built-in demo caller:

{{ demoOpenUrl }}

Example return shape:

{{ demoReturnUrl }}

Requires HTTPS and a browser with Web NFC (typically Chrome on Android). Without returnUrl, the result is shown in the app (standalone mode).
