return-apps

Helper apps that capture something and return via URL

Open an app from another web app with returnUrl. After Done, the result is redirected back as query params.

  • SignBack Handwritten signature → SVG
  • ScanBack QR / barcode scanner
  • GeoBack GPS coordinates
  • MapPickBack Leaflet map pin
  • PinBack Numeric PIN pad
  • NfcBack Web NFC tag reader
  • ColorBack Camera color eyedropper
