Return Apps

Toolbox you can install — or call with returnUrl

Open a tool to capture something, then download or copy the result. Calling apps can still open any tool with returnUrl (contract v1).

Start with Sign

Use your browser’s Install / Add to Home Screen to keep this toolbox one tap away.

apps.json · SDK · llms.txt · integration guide

  • SignBack Draw a signature → download SVG/PNG
  • ScanBack QR / barcode → copy value
  • GeoBack GPS → copy coordinates
  • MapPickBack Map pin → copy coordinates
  • PinBack Numeric PIN → copy digits
  • NfcBack Web NFC → copy payload
  • ColorBack Eyedropper → copy hex

Integrators: pass returnUrl + allowedOrigins. Success → value + format. Pin/sign use delivery=hash (parse the fragment, or use the SDK). Full guide: integration.md. 

import { openReturnApp, parseReturnResult } from './sdk/return-apps.mjs';

location.href = openReturnApp('pin', {
  returnUrl: location.href,
  allowedOrigins: [location.origin],
  state: 'order-42',
});

const { value, format, error } = parseReturnResult(location);
