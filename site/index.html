Toolbox you can install

Open a tool to capture something, then download or copy the result.

Use your browser’s Install / Add to Home Screen to keep this toolbox one tap away.

  • Sign Draw a signature → download SVG/PNG
  • Scan QR / barcode → copy value
  • Geo GPS → copy coordinates
  • Map Pick a point, measure a path, or draw an area
  • Pin Numeric PIN → copy digits
  • NFC Web NFC → copy payload
  • Color Eyedropper → copy hex
  • Level Spirit level / incline measuring tool
  • QR Text → QR
  • Compass Heading → copy degrees
