return.purified.app

Helper apps that capture something and return via URL

Open with returnUrl. Result comes back as value + format (contract v1). Pin/sign use delivery=hash by default.

apps.json · SDK · docs

  • SignBack /sign — signature → SVG · hash
  • ScanBack /scan — QR / barcode
  • GeoBack /geo — GPS coordinates
  • MapPickBack /map — map pin
  • PinBack /pin — numeric PIN · hash
  • NfcBack /nfc — Web NFC
  • ColorBack /color — color eyedropper

Open with returnUrl, optional allowedOrigins and delivery (query|hash). Cancel → error=cancelled. 

import { openReturnApp, parseReturnResult } from './sdk/return-apps.mjs';

location.href = openReturnApp('pin', {
  returnUrl: location.href,
  allowedOrigins: [location.origin],
});
const { value, format, error } = parseReturnResult(location);
